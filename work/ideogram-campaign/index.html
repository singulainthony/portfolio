One logo in, a whole campaign out

A nine-asset social campaign for North York Tech Help, generated with Ideogram 4.0 from a single logo reference, and the hand-built concept landing page that presents it.

North York Tech Help needed a whole season of social content: tips, offers, a scam warning, and covers for every profile. I’m a one-person business, so the real question was whether one logo file could carry a brand across nine formats without it drifting. I used Ideogram 4.0’s reference images to find out, then built a landing page to show the result.

This is an unofficial concept I made as a portfolio piece. It isn’t affiliated with or endorsed by Ideogram.

The campaign

Nine assets across eight aspect ratios, from a 3:1 Facebook cover to a 9:16 Story. Every one keeps the same logo, the same royal blue, and the same rising pixel squares from the mark, used as a motif that ties the set together.

How I made it

  1. Brief to prompt agent. I gave Hermes Agent (running DeepSeek V4.1 Flash) one brief: the palette as hex codes, a description of the logo, the audience, and each channel’s aspect ratio and crop rules. It wrote a prompt per format, every one following the same seven parts: format, logo lock, scene, layout zones, on-image copy, palette and motif, and camera.
  2. Ideogram 4.0 with the logo as a reference. Ideogram turns each prompt into an edit plan that lists exactly what must not change, which is how the logo survives every format. Eight assets were drafted on Turbo and the hero feed image was rendered on Quality.
  3. Batch variations in ComfyUI. Comparing a grid of options side by side makes the taste call faster than rerolling one image at a time.
  4. QA, written up for the product team. I noted what broke, not just what worked: a hex code from the prompt that got printed onto a calendar, a Facebook headline sitting outside the mobile-safe crop, and a logo that held on flat surfaces but split apart on a lawn sign. Each note came with a fix or a feature idea, such as safe-zone overlays for channel presets.
  5. Ship. A short Python script reads Ideogram’s export, resizes every render, and pulls out the prompts for the page.

The landing page

The page is hand-written HTML, CSS, and JavaScript with no framework, built with Claude Code. It shows every render at its true aspect ratio, lets you open any proof to see its exact prompt and Ideogram’s “stays the same” list, and closes with an enterprise pitch slide and speaker notes. I also wrote a headline A/B test into it: “One logo in. A whole campaign out.” against an emotional challenger aimed at solo owners.
